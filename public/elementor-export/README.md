## 🚀 How to Import Into WordPress (3 Simple Steps)

### Step 1: Import the Elementor Template
1. In your WordPress admin dashboard, navigate to **Templates > Saved Templates** (or **Theme Builder**).
2. Click the **Import Templates** button at the top.
3. Select and upload the file **`elementor-template.json`**.
4. Create a new Page (e.g., *Home*), click **Edit with Elementor**, click the **Folder icon (Add Template)**, go to **My Templates**, and click **Insert**!

### Step 2: Add the Additional CSS to WordPress Customizer
1. In your WordPress admin dashboard, go to **Appearance > Customize**.
2. Click on the **Additional CSS** tab.
3. Copy all code from **`style.css`** and paste it here.
4. Click **Publish**.

### Step 3: Add the Interactive JavaScript
1. Install the free **WPCode** plugin (or use your child theme's `footer.php`).
2. Add a new footer script snippet containing the contents of **`script.js`** wrapped in `<script> ... </script>`.
3. Save and activate!
